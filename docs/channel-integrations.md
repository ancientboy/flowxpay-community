# 上游支付通道接入

社区版内置模拟通道，适用于开发联调与评估。真实上游由客户提供自己的商户账号、官方接口文档与授权的测试凭据。若需要 FlowXPay 协助适配，请[联系商务](https://t.me/FlowXPay_nova)，先说明上游名称、国家、币种、代收或代付方向，以及是否有独立测试环境。凭据在确认合作后的受控渠道交接。

## 开发一个新适配器前

- 建单：确认签名、金额最小单位、商户单号、上游单号、限额和幂等规则。
- 查单：确认状态映射及超时后的原单核查。结果不明时保存原单号，避免重复派单。
- 回调：验证原始报文签名、来源和金额，处理重复、乱序与漏回调。
- 对账：确认账单字段、时区、结算周期和退款关联。按实际支持情况单独验证代付和退款。

社区版的模拟实现可从 [代收路由](../backend/cmd/api/collection.go)、[订单](../backend/cmd/api/payments.go) 和 [回调事件](../backend/cmd/api/collection_events.go) 阅读。商户侧接口见 [OpenAPI](openapi.yaml)。用独立数据库和上游测试环境验证新适配，再按获准范围安排实单验收。上游密钥、路由凭据和真实账单不应进代码库。
